---
title: Keyboard shortcuts
description: Navigate OCRFlow, work faster on the canvas, and use the command palette without leaving the keyboard.
---

OCRFlow has keyboard shortcuts for common navigation and canvas work. Press `?` anywhere in the signed-in app to open the in-app shortcut reference.

`Mod` means `⌘` on macOS and `Ctrl` on Windows and Linux.

Use the search field in the shortcut reference to find a shortcut by action or by its keys, such as `run`, `sidebar`, `⌘ K`, or `Alt 4`.

## Command palette

Press `Mod K`, or select the search control in the top navigation, to open the command palette. It searches and opens:

- Workspace pages including Dashboard, Projects, Pipelines, Jobs, Analytics, and Configuration.
- Your projects and reusable pipelines.
- Documentation pages, including API and HTTP integration guidance.
- Canvas actions such as running a graph, saving it, arranging nodes, and opening the model library.

Use the arrow keys to move through results and `Enter` to open the selected item. Press `Esc` to close the palette.

## Global shortcuts

| Action | Shortcut |
| --- | --- |
| Open command palette | `Mod K` |
| Show all shortcuts | `?` |
| Close a dialog or clear a canvas selection | `Esc` |
| Toggle workspace sidebar | `Mod B` |
| Go to Dashboard | `Alt 1` |
| Go to Projects | `Alt 2` |
| Go to Pipelines | `Alt 3` |
| Go to Jobs and uploaded documents | `Alt 4` |
| Go to Analytics | `Alt 5` |

## Canvas shortcuts

These shortcuts are available while editing a project or pipeline canvas.

| Action | Shortcut |
| --- | --- |
| Run all ready nodes | `Mod Enter` |
| Save the graph | `Mod S` |
| Open or close the model library | `Mod Shift P` |
| Use the select tool | `V` |
| Use the pan tool | `H` |
| Copy selected nodes | `Mod C` |
| Cut selected nodes | `Mod X` |
| Paste nodes | `Mod V` |
| Duplicate selected nodes | `Mod D` |
| Undo a node deletion | `Mod Z` |

Shortcuts are ignored while you are typing in a form field, except for `Mod K` and `Mod S`. The command palette stays the quickest way to discover pages, documents, model configuration, connections, and other actions as the workspace grows.
